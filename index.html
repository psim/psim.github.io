MDI-Readiness-Extended

An unofficial PowerShell script that reports whether an Active Directory environment meets the prerequisites for a Microsoft Defender for Identity sensor. It performs forest-wide scanning, network port and name resolution (NNR) checks, sensor v3.x readiness checks and capacity planning, and produces a self-contained HTML report.

A prerequisite it could not read is reported as not measured, never as a pass.
