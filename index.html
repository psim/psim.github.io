MDI-Readiness-Extended

An extended build of Microsoft's Test-MdiReadiness.ps1, the script that checks whether Active Directory is ready for a Microsoft Defender for Identity sensor. Adds forest-wide scanning, required network port and name resolution (NNR) validation, sensor v3.x upgrade readiness, capacity planning, a generated remediation script and a redesigned HTML report.

Its guiding rule: a prerequisite the script could not read is reported as unread, never as a pass.
